System Architecture

Robotic Overview

The robocat is a 4-legged robotic cat designed for security and surveillance in challenging environments. Built using rapid prototyping 3D-printed structural components, it houses an integrated multisensory payload designed to detect obstacles, analyze ambient atmosphere, and provide remote surveillance telemetry.

Subsystem Breakdown

Perception Layer

Sensor Suite

Equipped with an ultrasonic distance sensor for obstacle collision avoidance, an onboard gas sensor to detect hazardous environmental fumes, and an articulated periscope camera for live reconnaissance.

Compute & Control

Electronics & Processing

Powered by an Arduino Uno core microcontroller with an HC-05 Bluetooth transceiver module for wireless command input via mobile app. Utilizes a PCA9685 16-channel 12-bit PWM servo driver for synchronized multi-joint kinematics.

Mechanical Design

Physical Features

Custom 3D-printed lightweight chassis with articulated 4-legged gait mechanics. Each leg is independently driven by high-torque servos allowing omnidirectional movement and adaptable posture.

Human-Robot Interface

Voice Integration

Engineered for cloud assistant compatibility, including Amazon Alexa integration, making the robotic cat an intuitive, conversational, and interactive companion robot.
